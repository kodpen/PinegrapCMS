## 2026.3.3 — Performans kaydı anahtarı + ölçüm taşması

**Yeni:** `config.perf_monitor` (varsayılan açık). Kapatıldığında kayıtlar
silinir, ayarlardaki buton ve panel widget'ı gizlenir.

**Düzeltme:** `REQUEST_TIME_FLOAT` sıfır gelince süre 1,7 trilyon ms oluyor,
MySQL sessizce tavana (`4294967295`) kırpıyordu. Özet satırı biriktirdiği için
ortalama **sonsuza kadar** yanlış kalıyordu. Ekranda 56 milyar ms görülmesinin
sebebi buydu. Makullük kapısı: 0–3.600.000 ms dışı hiç yazılmaz.
