## Where do the rows come from? (3b, PR #2278; #2982)
- Several lines under `/create product` (`/oluştur ürün`) or its alias `/product` (`/ürün`): `ws_command_product()` sees a list (`ws_bulk_text_is_list()`: more than one non-empty line) and calls `ws_command_product_bulk()`; one line stays the single preview (`workspace-create-commands.md`). The list is laid out before any database call, so more than 200 rows are refused with the `import_products.php` pointer at once. Answer `done` with `bulk` {count, ignored}; the screen toasts `bulk_make_done`.
- A CSV/xlsx/xlsm/xls/ods file of the channel (#3014): `/create product` (or `/product`) with nothing after it, sent as a reply to the file's message (`ws_send`'s `parent_id` → `ws_command_product()` → `ws_command_product_file()`), or sent with the file (`ws_attach`: `ws_command_is_product_file()`; the file is posted without the command's text, then made into the card). The message must be of the same channel; `ws_bulk_create_propose()` reads it (`ws_bulk_message_table()`: read right, not deleted, `ws_bulk_file_is_table()`). With the attach form a file that is no table, or a person without the product right, is refused before the file is posted; a refusal of the rows after it comes back as `command` {type error}, toasted.
- Who may (architect #2999, `workflow/decisions-made-workspace-2.md`): anyone who may read the file's message, post in the channel and change products, someone else's file too; the drafts are the proposer's own, every row checked again at Apply.
- No entry point but the command: the channel menu item went in #2927, the pasted-list window and its keys (`bulk_make_intro`, `_placeholder`, `_go`) in #2982, the file's "Make products" button, `bulkMakeProducts()`, action `ws_bulk_create_propose`, flag `channel.bulk_products` and key `bulk_make_products` in #3014 (owner, 2026-10-29: the channel menu holds only the channel's own items, and a creation window or button inside the chat is not the right shape).
- Table: `ws_bulk_text_table()` (tab, else `;`, else `|`); a file through `ws_bulk_file_table()` (a spreadsheet via `pg_products_import_to_csv()`, a CSV with its first line's separator). `ws_bulk_table_rows()`: a first row naming a known column (`ws_bulk_header_fields()`: import names, English, Turkish) is a header, unknown columns named back; else the first cell is the name and short description, the first amount after it the price. Prices by `pg_products_import_price_cents()`.
- All go through `ws_bulk_create_card()`: ready, may post, product right, `ws_bulk_create_input()`, then a message of the person's own and the card under it, `request_id 0`. The command's message is the text as typed (`typed` option from `ws_command_run()`, cut at `WS_MESSAGE_MAX`); a file's is "Product drafts: N rows from “file”". Applied, `ws_bulk_step()` sets `ws_change_source()` to the person and a quiet log; decision "Bulk change by {person}: …".
