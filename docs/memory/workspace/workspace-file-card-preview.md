## What does a click on a channel file's name do?
- For a file the channel shows (a PDF, Word, Excel, .ods, .xls, .csv/.tsv, .pptx, a text file), the name and the card open it on the screen, never the file's address.
- A file the channel cannot show keeps the name as its link to the file.
