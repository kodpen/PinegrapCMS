My Notes: the screen redrawn

Today the list and the note stand on one ground with nothing between them, the rows touch, and the note’s place opens empty with a second “New note”: people in tests took the list for one note’s text and pressed “New note” every time. Redrawn: the list is a card of its own with a head and a line between its rows; the note is a second card; the screen opens on a note, never on an empty place.
