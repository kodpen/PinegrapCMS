## What do the Developer Terms allow?
- A non-transferable licence to use the developer resources "only as necessary to develop, test, and support" an integration, under Figma's Acceptable Use Policy.
- Credentials are not shared and are the only way in.
- A public integration must not "materially change the purpose or nature" once available.

## What does a public integration owe?
- Consents for the data it handles, a privacy policy saying the developer is responsible for that data, safeguards, and an immediate report of a security incident.
- No attribution rule for the integration; on termination Figma's marks stop being used and the developer resources are deleted.

## What can Figma change or end?
- Fees and rate limits on thirty days' written notice; access suspended or ended at any time (for a private integration of an Organization or Enterprise customer only on a good-faith belief of a breach).
- Liability capped; the developer indemnifies Figma; Figma may audit an integration.
