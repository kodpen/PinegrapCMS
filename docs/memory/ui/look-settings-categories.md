## Where did each category move?
- Step S5 of plan panel-old-screens moved every category: Commerce, Accounting, Bookings `look-commerce-settings-screens.md` (#10426); Maintenance, Firewall, Security, Features `look-settings-maintenance-security.md` (#10423); Mailboxes `look-settings-mailboxes.md` (#10431); Privacy to General, `screen.php`, `prep.php` and the page toolbar `look-settings-other-categories.md` (#10456); E-mail sending `look-settings-mail-sending.md` (#10458).
- Shared files that draw nothing old and needed no move: `modal.php`, `fragment.php`, `registry.php`, `search.php`, `drawer.php`, the `*.save.php` handlers, and the Workspace assistant and channel cards (`workspace_assistants.php`, `workspace_channels.php`).
- Inline styles left on purpose in every category: the popover arrows' position (Bootstrap places them) and rows a script shows or hides (`display`).
