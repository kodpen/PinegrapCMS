## What does a bell row carry?
- `module` from the row's `action`: shop, erp, content, team, system (`bell-panel.md`).
- `day`: `today`, `yesterday` or `earlier`, in the site's time zone.
- `button`: reply, show, join or approve, from `action` and the Workspace kind.
