Phone preview

The sheet of the plan “Preview on a phone”: a small window with a QR code in the designer, and the draft on the real phone, redrawn after each save. Sample: the design “Still Water Yoga” with the page “About us” on screen. The code drawn here is a stand-in, not a code a camera reads. Every label is in English as the step writes it.

  • The stop rules. The phone asks only while its tab is seen; after ten minutes without a change it asks less often, after an hour it stops and the line reads “Paused”. “Update” or a pull down asks once and starts again.
  • Coming back to the tab asks at once. “No connection” leaves by itself with the next answer; the page stays as last drawn.
  • A page removed from the design while the phone shows it: the line keeps its name, the body says “This page is no longer in the design.” and the list opens.
