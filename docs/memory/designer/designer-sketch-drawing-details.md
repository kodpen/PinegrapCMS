## How does "Page details" open?
- From "More" on a sketch page, or the command palette: one window over the dimmed map. Head "Page details" with the page beside it ("Page 7 · sketch page, not built yet"; "Classes · draft" on a built page).
- Seven rows, each made like a row of the Settings window: the name, one sentence, the control beside it.
- Every row has a value already, so "Save" needs no choice. The name is focused; Tab walks the rows, Enter saves, Escape cancels.
- Foot: the note "Links between pages are the map's arrows, as today.", "Cancel" (quiet), "Save" (filled).

## What are the seven rows?
- "Name": "Shown on the map and in the Pages window." Default: the name the tool gave.
- "Address": "Made from the name until you type one." The line under the field is the address the page will have.
- "Page type": "A type brings its widget; the page is built with it in place." A select: "Standard page" (default) and the types that have a widget.
- "In the menu": "Where the page's link goes. The menu itself is edited as today." A select, default "Not in a menu"; with a menu chosen a second select beside it names the item it comes after ("After “Home”").
- "Title": "For search engines and the browser tab. Empty, the name is used." Empty by default, the name as its placeholder.
- "Description": "One or two sentences for search results." A text area, empty.
- "Who may see it": "Access follows the folder the page is in." A select of folders, default the design's own; the line under it says who can open that folder's pages ("Everyone can open it.", "Only signed-in members of “Students” can open it.").

## What does a page type other than standard say?
- Under the select: "Brings the widget **Catalog listing**: built where the sketch has a Catalog box, else under the header."
- In the sketch the box of that kind is chosen in the chip's menu, as today.

## Where are the values kept?
- Before the build, with the sketch; the build makes the page with them. The frame's head takes a new name at once.
- On a built page the window shows and writes the page's own settings, the same ones the Settings window shows.

## What do errors, saving and a page the user may not change look like?
- A value that cannot be saved: the field gets the rose edge and the line under it says what is wrong ("A page needs a name.", "This address is used by the page “Classes”."); the first one is focused; nothing is saved until every row is right.
- Saving: the foot shows a spinner and "Saving…" in place of its note, both buttons dimmed. A save the server refuses brings the same rose line under the row it is about.
- Without the right to change the page every control is dimmed; the foot reads "You may see this page's details but not change them." and has only "Close" (quiet).

## What changes on a phone?
- The window takes the full screen; each control goes under its sentence, the two selects of "In the menu" one under the other; the foot stays at the bottom with "Cancel" and "Save", without its note.
