## Which keys does the tour take?
- Next, Back, Skip, Done; the right and left arrows inside the bubble; Escape unless a dialog, an open menu (the Preview menu at "see") or a typed field takes it (`escapes()`). The Escape the tour or the card takes stops there, so it does not also clear the selection or close the Prototype view. Skip, Done and Escape write the access's tour as seen.

## Where does the focus go?
- Focus goes to Next (or Done) at each stop and back to where it was at the end; a hidden live line reads "Tour, 3 of 5." and the sentence. A redraw of the count keeps the focus on the same button.
- A stop drawn while a dialog is open (a task chosen in the Help window starts while the window is still closing) takes the focus and is read out only once the bubble shows; the end then gives the focus to where the dialog gave it back.
