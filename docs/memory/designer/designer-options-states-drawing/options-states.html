Options: states, Transition and Transform

The sheet of the plan “More options in the Options panel”, steps DO10 to DO12: what an element looks like while it is hovered, focused or pressed, how it changes from one to the other, and how it is moved and turned. Sample: the button “See the timetable” in the hero of the page “Home”, design “Still Water Yoga”. The designer’s own parts are dark in both pictures. Every label is in English as the step writes it.

  • One row, four states. A press chooses a state; a press on the chosen one, or Escape, goes back to Normal. The state is held while this element and the Style tab are open: another element, another tab, the search and “Only what I changed” all go back to Normal.
  • The ring. A state that holds a value carries a ring on its segment. On Normal a section’s head carries one when a state changes a row in it; its tip names the states (“Hover and Focus change this section”).
  • Dimmed. Text, Spacing and Size and display keep one value for every state: their cards stay in place, closed, and read “same in every state”. Under a state the counts on the tab and the heads are that state’s, and an untouched section reads “as Normal”.

  • Grey is Normal’s. A row not set for the state shows Normal’s value in grey and writes the state’s own rule once it is changed. The dot’s arrow reads “Reset to Normal” and takes that one value out.
  • “Reset this state” clears every value of the chosen state on the selected elements in one undo step, without a question. With nothing set the line reads “Nothing is set for Hover.” and has no button.
  • “Only what I changed” lists Normal’s rows as today, then one line for each state that holds a value; “Show” opens the Style tab on that state. Its count adds the states’ values, and “Reset all” clears them too.

  • One value. A transition belongs to the element, not to a state: its rows stay open under every state with the mark “every state” and always change the same value. Their changed dot shows on Normal only.

More
  • Values. Move takes a length (a bare number is px), Scale a factor, Rotate and Skew degrees. The sliders run from 0.5 to 1.5 and from −180° to 180°, starting in the middle; a typed number may pass the slider’s ends.
  • “More” is a section’s one further level: a quiet row at its end, “Less” when open. It opens by itself while a row under it holds a value, so nothing that is set is ever hidden.
  • Origin is nine places in a square, the middle one until changed, with its name and per cents beside it. It is the point Rotate, Scale and Skew turn about.

State group. Height 28, segments 24 with corner 7, 2 apart; text 11.5 px, 600. The ring: 7 across, a 1.5 px line, 5 after the text; white on the chosen segment.

A head with a count and a ring

Shadow and effect1

A section’s head. The ring stands after the name and the count, never in place of the count: the count is Normal’s changed rows, the ring the states’.

Origin

Origin. Nine cells of 24, corner 9; a place 5, the chosen one 10 with a soft ring.

  • Keys. Tab reaches each state as it reaches a group’s buttons today; Space or Enter chooses, Escape goes back to Normal. In Origin the arrows move among the nine places.
  • Read out. The group is named “State”; a segment with a ring reads “Hover, has values”. Choosing a state is announced with what the canvas now shows.
  • No new button in the panel’s head, the page bar or the canvas bar: one row in the Style tab, and rows inside “Shadow and effect”.
