  • One list, one small button. The Easing list keeps its lines and gains the design’s stored curves and “Custom curve…”; every line carries the curve’s sign, blue for a stored curve. The button at the row’s end (tip “Edit the curve”) opens the graph under the row, starting from whatever is chosen. No window.

  • The graph. The dashed line is Linear. A handle moves across only between the two ends, and up or down as far as half a height past either line (−0.5 to 1.5), so a curve can overshoot and come back. The numbers under it are the same curve: either changes the other.

  • One choice for the design. None, Fade (the old page fades out as the new one fades in) or Slide (the new page comes in from “The right”, “The left” or “Below” while the old one leaves the other way). “Duration” (up to 1,000 ms) and “Easing” follow the look until changed, drawn in grey, as Transition’s rows do.
  • What is written. @view-transition { navigation: auto; } and the two rules of the old and the new page, inside the no-preference block, in the design’s variables file: no column, and a design never given a transition is byte for byte what it was. A browser without page transitions opens the page as before; no script.
  • Where it plays. On the site and in the Preview, when a link leads to another page of the same design. The canvas never plays it; “Play” plays it in the small figure.

An element repeated in a list cannot be kept across pages.

  • A switch and a name. Switched on, the element gets a name made from its kind and its section (“hero-picture”); the element given the same name on another page is its partner. “Name” lists the names the design has with the pages that hold them, then “A new name…” (small letters, digits and hyphens).
  • What is written. view-transition-name on the element’s own class, in User Styles; the class is added the first time, as Transition does. An element of the header or footer is on every page, so its switch alone is enough.
  • Said where it fails. A name used twice on one page keeps neither (a warning on both); with “Page transition” on None nothing is kept (one line that names where to choose); an element repeated in a list has the switch off.

  • The canvas stays still. A kept element is drawn as any other; its selection tag carries the link mark and the name, so a partner is found by reading.

  • No partner, no fault. A kept element whose name the next page does not have changes with its page; nothing is said.
