Canvas guides: distances, spacing and columns handled on the canvas

The drawing of plans/designer-canvas-guides.md. Under each board stands the step that builds it. The canvas bar is the designer's dark chrome in both pictures; the page on the canvas is a stand-in for a site's page in its own theme. Everything drawn over the page lives in the canvas's own layer: nothing of it is in the page's tree, its saved markup or the Preview. The numbers are examples; the labels are the steps'.

  • A side with no spacing shows a faint handle on the frame’s own edge, so spacing can be started from nothing.
  • The value is the scale’s step, then its pixels; with Shift or Alt it names the sides. One undo step per drag, written on release for the screen size the bar shows.
  • What it writes is what the Spacing box writes. The bands show only on the one selected element, and go while it is dragged to another place.

  • The handle sits on the side edge of the selected column; the edge steps from column to column, never between.

  • One switch, no button in the bar. The four rows above it are today’s and stay as they are; the badge counts “Canvas guides” while it is on.
  • The key rows are not buttons: they say which key does what, and are dimmed while the switch is off. Shift+G is drawn as an example; CG5 takes a key the shortcuts list has free.
