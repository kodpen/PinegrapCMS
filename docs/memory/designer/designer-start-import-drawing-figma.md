## How does the Figma start open?
- Pane title "Start from a Figma file", one line, then the account line: the Figma tile, "Connected as <name>", the link "Manage in Connections".
- One field, "Figma file link" (placeholder `https://www.figma.com/design/…`, help "In Figma: Share, then “Copy link”."), then a grey line that a View or Collab seat reads only a few files a month and more imports need a Dev or Full seat.
- Foot: "Cancel" quiet, "Read the file" filled; grey until the field holds a link. Enter in the field presses it.
- Not connected: the pane is an empty state, "Figma is not connected", with the quiet button "Connect in Connections" and a line for a person who may not open Connections (ask a manager of the site).
- Token no longer accepted: an amber notice above the field with the words of the Connections page and "Manage in Connections".
- Busy: the button reads "Reading…" with a spinner, the field is locked, four grey tiles stand where the frames will be. A tile shows its name and size first, its picture when it arrives.

## How is the frame list laid out?
- Head: the Figma tile, the file's name, "n pages, n frames", and the ghost button "Another file". The file's pages are groups with their frame count and a link "Tick all" / "Untick all" at the right.
- A frame is a tile, four a row: picture, name, size, a tick box at the top left. The whole tile is the tick; Space ticks the tile in focus, the arrow keys move between tiles.
- Ticked when the list opens: the frames of the file's first page that are as wide as a desktop screen.
- A frame whose picture did not come shows the grey picture sign and can still be ticked.
- Foot: the count ("5 of 14 frames ticked: 5 pages"), "Back" ghost, "Next" filled. Nothing ticked: "Next" is grey. Over the most frames of one import the count turns amber and says how many to untick.
- The list scrolls inside the pane; the head and the foot stay. The file read is kept while the window is open, so "Another file" and "Back" spend no call.

## What does a link that cannot be read say?
- One red line under the field: not a Figma link; the connected account cannot open the file (ask the owner to share it, or save another account's token); Figma did not answer.
- The limit is an amber notice of its own, "Figma's limit for this account is reached", with the time to try again and that what was read so far is kept.

## What changes at 390 px?
- The window is the full screen, the starts a strip (the window's own, ST2). "Manage in Connections" leaves the account line; the tiles go two a row; the foot's buttons stack full width with the count above them.
