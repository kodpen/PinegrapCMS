D3 · “Import”: the file is read, then asked · DV5The file box of the browser opens first. What the file would change is listed before anything changes.

Import variables from brand.tokens.json?

The file holds 23 tokens.

  • 17 values of this design change: 8 colours, 6 of type, 3 of shape.
  • 4 come as your own variables: 3 colours and 1 size.
  • 2 are left out: a gradient and a duration have no place in a design's variables.
