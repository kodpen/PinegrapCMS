My library

The sheet of the plan “My library”: a section saved to the site's own library, found as the first group of the Blocks list, added to any page as a copy, kept in order in “Manage library”, and carried to another site as a file. Sample: the library of the site “Studio Calm” with six items. Every label is in English as the step writes it.

  • Keys. Enter saves, Escape closes. A name and a group hold 60 characters; the field takes no more. An empty name keeps “Save” off.

  • Adding. Drag or double-click, exactly as a ready block is added. The copy is the page's own; changing it changes no other page and not the item.
  • Search reads an item's name and its group. While a search is typed the row “Manage library” is not drawn.

The other reasons, as the window words them

“photo.json” is not a library file.
“old-kit.json” holds an event attribute (onclick) in the item “Promo banner”.
“old-kit.json” holds an address that is not allowed (javascript:) in the item “Promo banner”.

  • The file's name is the site's name with “-library”. One chosen item gives a file with one item; the format is the same.
  • All or nothing. One item that fails refuses the file: the reason names the item, and nothing of the file is kept.
  • What a file never holds: a record's data, a member's content, a key or a connection. A binding travels as a setting and is matched by name on the other site (L4).
