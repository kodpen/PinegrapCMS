Each picture becomes the model of one page.BackNext
  • The number on a tile is the page’s place; dragging a tile changes the order. The bin takes a page out without asking: the file is still on the person’s computer.
  • A page’s name is the file’s name, or “file, page n” for a PDF. It becomes the page’s name in the design and can be changed there.
  • A tile is the same card as a Figma frame’s (B5 of figma.html), with the page’s number and the bin in its head in place of the tick.
  • The drop place shrinks to one row under the tiles once a page is there. It is not on the Design examples screen yet and becomes an example from this sheet.

C3 · Busy and refused files · ST6A file is a row while it is read; a refused one says why and leaves the others alone.

poster-print.pdfThis file is larger than the 32 MB this site takes in one upload.
catalogue.pdfThis PDF has 64 pages. One design takes 20 pictures; the first 20 were added.
  • The numbers (32 MB, 20 pictures) are examples: the size is the site’s upload limit, the count is the one ST6 sets.
  • The cross on a row stops a file being read or clears a refusal. “Next” waits while a file is being read.

  • The swatches of a row are the colours found; the ringed one is the answer. A press on another swatch changes it in place: no picker here.
  • “Ask me the questions” opens the five questions of DV4 with the two colours chosen.
  • “Create design” opens the design in the Sketch tool, each page with its picture as the reference under the frames (drawn on the sketch sheet, step SK7).
