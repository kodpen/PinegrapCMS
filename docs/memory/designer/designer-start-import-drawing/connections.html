  • One field. A personal access token is all Figma needs: no app, no return address. The page has no “Connect” button that leaves the site.
  • The buttons: “Save” filled, “Save and try” quiet, as on every service page. “Save and try” fills the Status card’s name; “Save” alone stores the token and shows “Not tried yet”.
  • The secret is kept as Connections keeps a service’s secret: never printed back, in no log. Typing a new token over a stored one replaces it.
  • The two scopes: “File content” reads a file, its frames and pictures; “Current user” lets the page say whose token it is. A token with the first scope only is stored too: the Status card then reads “Connected” with no name.
  • On the Connections list Figma is one row under the design tools, with the same pill as this page’s head. There is no Canva row: Canva has no connection.
  • Who sees it: the gate of the Connections screen. A designer who may not open it reads in the New design window that a manager connects Figma.
