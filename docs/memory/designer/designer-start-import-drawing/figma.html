  • Ticked when it opens: the frames of the file’s first page that are as wide as a desktop screen. A person who wants exactly that presses “Next” at once.
  • A tile is the “Choice cards” card with the frame’s picture inside it: the name and the tick in its head, the size as its note; a ticked one wears the chosen card’s ring. The tick is a square, since more than one is chosen.
  • A press anywhere on a tile ticks or unticks it. Space does the same on the tile in focus; the arrow keys move between tiles.
  • “Tick all” / “Untick all” is a link at the right of a page’s name, never a button. A frame whose picture did not come shows the grey picture sign and can still be ticked.
  • The count stands in the foot beside the buttons. With nothing ticked “Next” is grey. Past the most frames one import takes it turns amber: “16 frames ticked: untick 4. One import takes 12.”
  • “Another file” goes back to the link field; “Back” does the same. The file read is kept while the window is open, so coming back spends no call. The list scrolls inside the pane; its head and the foot stay.

Copy the reportGot itOpen the design
  • Running: the page’s own requests carry the import while the designs home is open; where the site’s general job runs, it goes on with the home closed too.
  • Waiting: Figma’s limit was met; the line names the time it tries again and needs no press.
  • Paused: the home was left and no job runs. “Continue” (quiet) goes on from the frame it stopped at; “Stop” (ghost) asks first with the dialog of B12, then removes the pages made and what was fetched.
  • Done: “Report” is a link in the line and opens the New design window at the report’s pane, its foot then reading “Copy the report”, “Got it”, “Open the design”.
  • The line goes when “Got it” is pressed there, or 14 days after the import ended. Opening the design does not remove it.
  • No button is added to the card’s head or the home’s bar; the card’s menu gets no row either.

  • One rule in both places: “Stop” in the running window (B8) and “Stop” on the paused card (B11) open this dialog; neither stops at once.
  • Rose rows say what goes: the pages made so far and what the server fetched into the file manager.
