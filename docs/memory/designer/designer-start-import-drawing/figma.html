  • Ticked when it opens: the frames of the file’s first page that are as wide as a desktop screen. A person who wants exactly that presses “Next” at once.
  • A tile is its own tick: a press anywhere on it ticks or unticks. Space does the same on the tile in focus; the arrow keys move between tiles.
  • “Tick all” / “Untick all” is a link at the right of a page’s name, never a button. A frame whose picture did not come shows the grey picture sign and can still be ticked.
  • The count stands in the foot beside the buttons. With nothing ticked “Next” is grey. Past the most frames one import takes it turns amber: “16 frames ticked: untick 4. One import takes 12.”
  • “Another file” goes back to the link field; “Back” does the same. The file read is kept while the window is open, so coming back spends no call.
  • The list scrolls inside the pane; the head with the file’s name and the foot stay.

  • The frames with notes come first open, one at a time; “Carried whole” rows do not open. A note names the layer, says what happened and what it means on the page.
  • “Not made” opens to its reason (“Figma did not give this frame’s pictures. Start again with this frame ticked.”); the other pages are made.
