## How was the list made?
- Counted on 2026-11-27 from the 79,422 Turkish keys: each word by the number of keys it is in, the panel's labels kept, plain words (every, first, again) left out. Written as English=German; a verb as the button's infinitive, formal "Sie" in sentences.
- A term German spells the same keeps its English and is not listed: Design, Team, Link, Code, Newsletter, Status, Server, Shop, Name, Text, Designer, Manager.
