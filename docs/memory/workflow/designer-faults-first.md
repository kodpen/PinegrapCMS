## What comes first?
- Owner (2026-11-26, in the architect's window): "lütfen tasarımcı ekranını iyileştirelim. öncelik olsun". He said it after a day of reports from his own work in the Page Design Studio: a stutter in a large design, a label written over the page bar, a phone preview window with no code and no reason.
- Architect's reading, not his words: an open `bug` issue about the Page Design Studio is given out before a plan step in the places a coordinator fills. The plans do not stop; `plan-priority.md` orders everything else as before.

## How does a coordinator keep it?
- Before a freed place takes a plan step, the open `bug` issues are read (`coordinator-no-plans.md`); one about the designer goes first. One issue, one worker, one PR.
- Two issues on the same file or screen are not worked side by side (`coordinator-worker-steps.md`): the second waits for the first PR to land, or goes to the same worker.

## How long does it hold?
- Until the owner says otherwise. The architect removes this file then.
