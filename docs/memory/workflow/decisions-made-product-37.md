## How does a design template get its own look? (2026-11-07)
- Owner (2026-11-07): the templates must not all look alike (the same bands with only the site name and intros changed). A section a template needs that the palette lacks is built first as a palette block family and added to the palette, as was done for the news templates; the template then places it. Each template has a character of its own, and motion where the sector calls for it (the phone launch template as an Apple-like product page). Reason: alike templates are hard to polish later, and the palette grows with every template. Rule: `designer/design-template-own-look.md`.
- Owner (2026-11-07): afterwards every other shipped design gets one polishing round. Plan `plans/design-template-own-looks.md` (Launch first).
- Owner (2026-11-07, later): go ahead with the retrofit and add more palette blocks, but no duplicate blocks: where a block with the same structure already exists (only the content differs), it is reused. Reason: one block to polish instead of copies.
- Running sites keep their pages: a design records the edition it started from; a raised template version reaches new openings only.
