## How does My Notes look with groups?
- My notes: the person's groups as folders (colour dot, name, count, chevron; a lock when locked), each holding its pinned notes first, then its order; then the notes in no group, as today. Shared with me: groups shared with the person as folders with their owner's name, then notes shared one by one.
- A member's notes in a group carry their face. A locked group shows its name and lock only, no count, until the PIN opens it.
- New note makes the note in the group of the open note, else in none.

## What do the tabs show?
- Over the note's title: the group's colour and name, then a tab per note (title cut short, lock and people marks), the open one marked, and + for a new note in the group. A note in no group has no tabs.

## What does a move ask?
- Into a shared group: everyone in the group will see the note. Out of one: they lose it unless it is shared with them on its own. A shared note into a locked group: locking takes its shares back. Somebody else's note into a shared group, or a member moving a note of the group that is not theirs: refused with a sentence.

## How is the lock set up and opened?
- Toolbar: Lock (`bi-lock`). Not set up: a dialog with the PIN twice and "Ask for the PIN again after" (Every time, 1, 5, 15, 30, 60 minutes, Until I sign out). Set up: Lock now, Change PIN, Change the time, Turn off.
- A locked note opens to a lock pane: its title, a masked numeric PIN field, Open, "Forgot your PIN?", which sends the code and says to which address (masked), then asks for the code and a new PIN. After five wrong PINs: try again in 15 minutes or use a code by e-mail.
- The e-mail, in the person's language: the code, that it works for 10 minutes, and to change the PIN if they did not ask for it.

## How is a media block drawn?
- A picture fills the width up to 20 rem high and opens the image viewer; a canvas adds Edit the picture (M3). Video and sound get players. A PDF or another file is a card (icon, name, size) opening the file preview. Behind a closed lock nothing of it is drawn.
